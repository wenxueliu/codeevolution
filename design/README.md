备选方案、风险与验收），与 `docs/` 下的产品/架构/使用文档互补。

## 约定

- 文件名使用 kebab-case，与能力名对应；
- 文档头部保留「版本 / 状态 / 日期 / 核心代码 / 数据来源 / 对外入口」元信息；
- 正文至少覆盖：背景与问题、目标与非目标、方案总览、判定/业务规则、数据与接口、
  兼容与迁移、备选方案与取舍、风险与边界、测试与验收；
- 设计变更时更新版本号与变更说明，不新建重复文档。
